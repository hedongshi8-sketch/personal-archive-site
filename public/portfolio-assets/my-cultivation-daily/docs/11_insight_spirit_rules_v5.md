# 《我的修仙日常》感悟与元神出窍规则 v5

## 1. 目标

把“感悟”和“元神出窍”从单点教学机制，改成大世界里随时可触发、受条件影响、可复盘、可深化的开放规则。

## 2. 感悟规则

感悟不是蒲团专属事件，而是玩家和世界规则碰撞后产生的理解变化。

### 2.1 感悟可以从哪些地方来

至少应支持以下来源：

| 来源 | 说明 | 结果表现 |
| --- | --- | --- |
| 观察异常 | 看到灵脉、隐纹、裂缝、风向、气流不对 | 获得规则短句或札记条目 |
| 成功使用能力 | 显形、爆炸、护体、御剑、元神、传音 | 明白能力如何改变对象 |
| 失败后改法 | 符纸没亮、炸错位置、听不清、出窍失稳 | 对规则边界产生理解 |
| 战斗或受击 | 触发护体、闪避、反应迟滞 | 认识肉身与灵气的关系 |
| 炼丹 / 试药 | 药性冲突、回灵、心神波动 | 认识身体、药性与心境 |
| 天气 / 昼夜 / 季节 | 雨、风、雷、夜色、寒热变化 | 认识环境对灵气的影响 |
| 地形 / 地脉 | 山沟、灵泉、断桥、阵眼、岩障 | 认识地势对规则的承载 |
| NPC行为 | 态度变化、隐瞒、共鸣、误导 | 认识关系和修行的交叉 |
| 重复试错 | 多次做同一事后换路 | 认识“同一规则可多解” |
| 梦境 / 复盘 | 睡前整理、短暂入定、回忆旧句 | 让理解固化为札记 |

### 2.2 感悟如何表现

感悟应表现为：

- 一句短提示。
- 一条札记新增记录。
- 一个新的观察方式。
- 一个更稳定或更清晰的规则理解。

不应表现为：

- 大段弹窗教程。
- 单独经验条。
- 只有在蒲团上才跳出的唯一结算。

### 2.3 蒲团的正确作用

蒲团不是感悟唯一来源，只是下面三种作用：

1. 安神。
2. 复盘。
3. 深化。

它可以提高感悟整理效率、降低出窍风险、帮助突破，但不能独占“理解发生”的资格。

## 3. 元神出窍规则

元神出窍应成为一种**可自由尝试、但有条件和代价**的能力。

### 3.1 基本原则

- 不是只能在蒲团上出窍。
- 不是无限远。
- 不是无风险。
- 不是万能解法。
- 不是替代全部探索的外挂。

### 3.2 可尝试位置

| 位置类型 | 是否可尝试 | 说明 |
| --- | --- | --- |
| 蒲团旁 | 可尝试 | 最稳，适合教学与回收 |
| 静室 / 洞府角落 | 可尝试 | 需肉身安全 |
| 灵泉旁 | 可尝试 | 可作为安神锚点 |
| 阵眼附近 | 可尝试 | 受阵法稳定度影响 |
| 古树下 / 安静地带 | 可尝试 | 需无明显敌意扰动 |
| 危险地带 | 可强行尝试 | 但风险高，可能失控或被惊扰 |

### 3.3 风险因素

| 风险项 | 影响 |
| --- | --- |
| 心境 | 越乱越容易失稳、偏航、提前回窍 |
| 肉身安全 | 肉身一旦受威胁，元神容易被拉回 |
| 距离 | 离肉身越远，消耗越大 |
| 环境扰动 | 风、雷、爆炸、敌意、灵压会增加风险 |
| 阵法 / 屏障 | 可阻隔、扭曲或放大灵性信息 |

### 3.4 安神锚点

锚点不是专属按钮，而是“更安全的尝试地点”。

可作为锚点的例子：

- 蒲团。
- 静室。
- 灵泉边。
- 阵眼旁。
- 洞府安全角。
- 安静的古树下。

锚点的作用是降低风险、延长时间、减少偏航，不是开启能力的唯一条件。

### 3.5 距离规则

元神离肉身越远：

- 消耗越快。
- 画面越不稳。
- 可交互范围越窄。
- 回窍压力越大。

距离不是硬数值炫耀，而是风险表达。它应该让玩家感受到“远观有代价”，而不是把元神做成无成本镜头。

### 3.6 元神可以做什么

- 观察灵性痕迹。
- 远观不易看见的对象。
- 偷听传音。
- 看见元神或残念。
- 发现隐藏层、阵脚、暗纹。

### 3.7 元神不能自动解决什么

- 不能替代所有移动。
- 不能无限距离探索。
- 不能在肉身极危时白嫖安全。
- 不能把所有线索一次看完。

## 4. 传音与元神的关系

传音是信息生态，不是独立任务频道。

| 状态 | 传音表现 |
| --- | --- |
| 肉身状态 | 只听见片段、噪声、方向和情绪 |
| 元神状态 | 能听见更完整的句子，但仍可能残缺或有立场 |
| 阵法 / 遮挡 | 可能让传音变形、延迟或失真 |
| 多人场景 | 可能有多个声音源互相干扰 |

传音可以带来线索，但不能是唯一推进方式。它更像江湖信息流的一部分。

## 5. 与蒲团的关系

蒲团更适合：

- 安神。
- 复盘。
- 整理感悟。
- 降低出窍风险。
- 作为阶段性结算点。

不适合：

- 作为唯一感悟地点。
- 作为唯一出窍地点。
- 作为所有理解的起点和终点。

## 6. 结果沉淀

任何一次感悟或出窍，若足够明确，应能沉淀到：

- 修行札记。
- 传音札。
- 关系录。
- 对象变化记录。

它们不是弹窗替代品，而是让玩家以后可以主动回看、比较、复盘的长期记录。

## 7. 结论

感悟要“随处可能发生”，元神要“随处可以尝试，但受条件影响”。蒲团只是帮助整理和稳定，不是垄断理解与出窍的门槛。
