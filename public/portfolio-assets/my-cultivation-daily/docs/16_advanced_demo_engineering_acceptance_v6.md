# 《我的修仙日常》高级Demo工程验收清单 v6

## 1. 用途

本清单给 Demo验收模块 `REV-20260804-12` 使用。验收对象是 Godot 高级开放小区域 Demo，不是文档本身。

## 2. 工程任务清单

| 编号 | 任务 | 最低完成标准 |
| --- | --- | --- |
| T01 | 重构地图层 | 至少 `Ground / Transition / Path / Decor / Occlusion` 五层 |
| T02 | 建立八个场景点 | 洞府、灵田、山门、灵泉、废阵、茶摊、药铺、断桥均可辨识 |
| T03 | 搭建物件簇 | 20 个以上非重复装饰物件，按场景簇摆放 |
| T04 | 接入遮挡/Y-sort | 角色能正确在石灯、NPC、树影、屋檐等前后穿行 |
| T05 | 接入角色动画 | idle + 上下左右四向移动 |
| T06 | 接入 NPC 动画 | 至少 idle 或朝向变化 |
| T07 | 接入环境循环动画 | 至少水波、灯火、草/叶、灵气、NPC idle 五类 |
| T08 | 接入交互特效 | 至少显形光纹、爆炸尘土、元神轮廓、传音波纹四类 |
| T09 | 接入局部光源 | 至少石灯、灵泉、废阵/洞府烛火三处 |
| T10 | 接入持久状态变化 | 裂岩破碎、灵田采空、废阵显形/阵眼激活至少三项 |
| T11 | 保持 UI 克制 | 默认主HUD无变量总账，DebugOverlay 默认关闭 |
| T12 | 输出证据包 | 4 张截图 + 30-60 秒录屏或逐帧证据 |

## 3. 数字硬门槛

- 5 层以上画面/工程分层。
- 4 个以上色彩区域。
- 20 个以上装饰物件。
- 3 个以上局部光源。
- 5 类以上环境循环动画。
- 4 类以上交互特效。
- 3 个以上对象持久状态变化。
- 4 张截图。
- 1 段 30-60 秒录屏或等价逐帧证据。

## 4. 截图证据要求

| 截图 | 必须证明 |
| --- | --- |
| 默认画面 | 地图层级、场景簇、克制 HUD、无 DebugOverlay |
| 显形前后 | 隐藏符纹/阵眼/空气墙发生可见变化 |
| 爆炸前后 | 裂岩或封石破碎，路径或对象状态改变 |
| 元神/传音 | 画面/声音层差异、传音片段与完整度差异、风险提示 |

截图不得只截 UI 文本，必须包含世界对象。

## 5. 录屏或逐帧证据要求

30-60 秒录屏至少覆盖：

1. 玩家移动和 Y-sort/遮挡。
2. 一个环境循环动画。
3. 一次显形或爆炸交互。
4. 一次对象持久状态变化。
5. 一次元神或传音视听层差异。

若无法录屏，必须用逐帧截图和说明替代，至少 6 帧：靠近前、靠近时、输入瞬间、生效中、生效后、归档。

## 6. README 必填项

README 必须写：

- Godot 版本。
- 启动方式。
- 操作方式。
- 截图路径。
- 录屏或逐帧证据路径。
- 资产名称、作者、来源 URL、许可、是否需要署名。
- 图片导入设置：像素过滤、缩放、tile size。
- 工程节点结构说明。
- 已知未完成项。

## 7. 一票否决项

以下任一项出现，判不合格：

- 默认截图仍是大面积硬矩形色块。
- 没有 20 个装饰物件，或物件仍像孤立测试点。
- 没有局部光源。
- 没有环境循环动画。
- 没有角色移动动画。
- 没有 Y-sort/遮挡证据。
- 交互结果只靠文字说明。
- 显形、爆炸、元神、传音没有可见差异。
- 没有 4 张截图。
- 没有 30-60 秒录屏或逐帧证据。
- README 没有资产许可记录。
- 默认画面出现变量总账或 DebugOverlay。

## 8. 结论

验收标准从“能跑”升级为“像游戏”。Demo 必须用工程结构和证据证明：场景有层次，对象有状态，能力有动效，交互有因果。
