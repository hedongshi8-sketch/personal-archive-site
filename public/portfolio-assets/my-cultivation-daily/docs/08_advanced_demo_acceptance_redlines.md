# 《我的修仙日常》高级Demo验收红线清单

## 任务信息

- 项目ID：`P-20260802-我的修仙日常`
- 任务编号：`REV-20260804-10`
- 用途：给系统体验模块 `REV-20260804-11` 和 Demo验收模块 `REV-20260804-12` 作为硬验收红线。

## 一票否决

后续 Demo 若出现以下任一项，应判返工：

1. 色块地图：大面积硬矩形地块，无边缘过渡、道路、装饰和材质变化。
2. 孤立贴图点：对象像测试按钮散落，没有物件簇、空间关系和场景叙事。
3. 纯文字交互：交互结果只靠 toast / HUD 文案说明，世界对象没有变化。
4. 无动画反馈：角色、NPC、环境、能力效果全部静止。
5. 无环境状态变化：爆炸后岩石不碎，显形后机关不变，采集后资源点不变。
6. 所有信息靠 HUD 文案说明，缺少对象亮起、符纹、光影、粒子、声音方向等反馈。
7. 素材风格混乱：16x16、32x32、高清图、AI图、不同透视角混用且无统一处理。
8. 无 Y-sort / 遮挡：角色永远压在所有物件上或被错误遮挡。
9. 无接地感：角色和物件没有脚下阴影、墙角暗部或环境光。
10. 默认截图不像玩家画面，而像调试场、功能验证面板或素材拼贴。

## 最低通过线

### 画面层级

- 至少 5 层视觉组织：地面、过渡、装饰、遮挡/Y-sort、特效/光照。
- 至少 4 个区域有明确视觉身份：洞府、灵田、山门、灵泉/废阵。
- 至少 20 个装饰物件按簇摆放。
- 至少 3 个局部光源或发光对象。

### 动画反馈

- 角色有 idle + 4向移动动画。
- NPC 至少有 idle 或朝向变化。
- 至少 5 类环境循环动画。
- 至少 4 类能力/交互特效。

### 交互反馈

- 显形符必须改变场景对象。
- 爆炸符必须改变路径或对象状态。
- 元神必须改变画面/声音/可见对象层。
- 传音必须有肉身与元神两种呈现差异。
- 采集点必须有采前/采后状态。

### 证据

- 至少 4 张截图：默认、显形、爆炸、元神/传音。
- 至少 1 段 30-60 秒短录屏或等价逐帧证据。
- README 写明资产、许可、导入设置、操作和验收路径。

## 禁止把以下内容当成“高级”

- 多放几个贴图。
- 多写几行提示文字。
- 加一张漂亮背景但玩家不能与之交互。
- 把调试变量隐藏后就算 UI 合格。
- 只证明能跑，不证明好看、有手感、有层次。
- 只用截图证明，不证明交互前后变化。

## 对本项目的硬判断

当前 Demo 已经不是最差的色块白盒，但仍处于“可运行交互草图”。下一轮必须证明：

1. 场景有层次。
2. 对象有状态。
3. 能力有动效。
4. 互动有因果。
5. 截图像游戏。
6. 录屏有手感。

## 结论

Demo 验收不能再停留在“无报错、能互动、没有图集贴屏”。最低标准要提高到：默认画面能让人相信这是一个像素游戏场景，交互录像能让人看见世界因为玩家行动发生变化。
