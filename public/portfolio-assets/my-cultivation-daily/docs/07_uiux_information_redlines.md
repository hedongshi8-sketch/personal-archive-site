# 《我的修仙日常》UI/UX信息呈现红线清单

## 任务信息

- 项目ID：`P-20260802-我的修仙日常`
- 任务编号：`REV-20260804-04`
- 用途：给系统体验模块 `REV-20260804-05` 和 Demo 验收模块后续整改使用。

## 一票否决

后续文档或 Demo 若出现以下任一项，应直接判返工：

1. 默认主画面常驻显示全量变量总账。
2. 主画面常驻 `已解锁 / 未解锁` 能力列表。
3. 主画面常驻显示所有资源、所有关系值、所有剧情标志位。
4. 用网页问答、按钮菜单、弹窗选择代替地图移动和场景交互。
5. 开场把御剑、符箓、丹药、元神、传音全部做成按钮菜单。
6. 能力获得只表现为变量从 `false` 变成 `true`，没有场景事件或玩家记忆点。
7. 显形符、爆炸符、护体符、元神、传音没有世界对象反馈。
8. 教学依赖长文本说明，没有观察、试错、失败反馈和札记沉淀。
9. 调试变量默认显示在玩家画面。
10. 任何签到、活跃度、登录奖励、强制日课、资源KPI式界面。

## 当前 `state_label` 的红线判定

当前脚本中的 `state_label` 默认常驻显示：

```text
形态 | 心境 | 显形符 | 爆炸符 | 传音 | 理解 | 灵草 | 灵石 | 林小满关系
```

这不应作为玩家HUD。它只能作为 Debug Overlay，默认关闭。

## 必须拆分

| 当前信息 | 正确归属 | 禁止形式 |
| --- | --- | --- |
| 形态 | 切换瞬间短提示 + 画面/声音变化 | 常驻“形态:肉身/元神” |
| 心境 | 临界警示 + 状态菜单 | 常驻数字 |
| 显形符/爆炸符 | 符箓匣 + 当前选中图标 + 场景反馈 | 已解锁/未解锁列表 |
| 传音 | 场景声源 + 传音札 | 常驻“完整/片段” |
| 理解 | 修行札记 | 常驻“已记录/未完成” |
| 灵草/灵石 | 行囊 + 获得短提示 | 全程常驻资源总数 |
| NPC关系 | 关系录 + 对话变化 | 常驻关系数值 |

## HUD允许项

默认主画面只允许：

- 当前可交互对象提示。
- 当前选中能力/符箓图标。
- 立即影响行动的风险提示。
- 2-3秒淡出的获得/变化提示。

## 主动菜单必须承载

- 修行札记。
- 符箓匣。
- 行囊。
- 地图。
- 关系录 / 传音札。
- 设置和 Debug 开关。

## 场景反馈必须存在

- 显形符：隐藏符纹、灵脉、机关显现。
- 爆炸符：岩障碎裂、路径打开、碎石残留。
- 护体符：危险瞬间护罩显现。
- 元神：画面色调、声音层、可见对象变化。
- 传音：肉身听片段，元神听完整；声音来自空间方向。

## 验收用问题

每个新增UI元素都必须回答：

1. 玩家此刻是否必须知道它？
2. 它能否只在情境出现？
3. 它能否通过世界对象或动画表达？
4. 它是否更适合进入主动菜单？
5. 它是否只是开发者想看的变量？

如果回答不清楚，不允许进入主HUD。

## 结论

默认玩家界面必须像游戏，不像调试面板。系统越底层，越应该通过世界反馈和主动查看表达；越不是当下决策必需，越不该常驻屏幕。
