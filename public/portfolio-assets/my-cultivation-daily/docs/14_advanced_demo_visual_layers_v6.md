# 《我的修仙日常》高级Demo画面层级规格 v6

## 1. 目标

把当前“脚本生成静态 Sprite 测试点”升级为有空间厚度、视觉身份和构图焦点的 Godot 2D 像素场景。

## 2. 必须建立的工程层级

| 层 | 节点建议 | 内容 | 通过标准 |
| --- | --- | --- | --- |
| 地面基础层 | `TileMapLayer_Ground` | 洞府地板、湿土、石路、水面、废阵地面 | 材质差异清楚 |
| 边缘过渡层 | `TileMapLayer_Transition` | 草边、水岸、田埂、台阶、门槛 | 没有硬矩形切边 |
| 道路/路径层 | `TileMapLayer_Path` | 山门石路、泥路、断桥边缘 | 玩家能看懂可走区域 |
| 装饰层 | `DecorRoot` | 桌椅、书架、草丛、碎石、药架、茶炉 | 20 个以上装饰按簇摆放 |
| 遮挡/Y-sort层 | `YSortRoot` | 树冠、屋檐、门框、石灯、NPC、大石 | 角色前后遮挡正确 |
| 交互对象层 | `InteractableRoot` | 灵田、裂岩、阵眼、灵泉、NPC、断桥 | 每个对象有状态字段 |
| 特效层 | `EffectRoot` | 粒子、波纹、尘土、显形线、元神轮廓 | 至少 4 类交互特效 |
| 光照层 | `CanvasModulate/PointLight2D` | 石灯、灵泉、废阵、洞府烛光 | 至少 3 个局部光源 |
| UI层 | `CanvasLayer/HUDRoot` | 交互提示、能力图标、短提示 | 克制 HUD，无变量总账 |
| Debug层 | `DebugOverlay` | 调试变量、碰撞、状态 | 默认关闭 |

## 3. 八个场景点画面规格

### 3.1 洞府

- 色彩：暖褐、烛黄、石灰。
- 物件簇：蒲团、书架、丹炉、储物箱、烛台、门框。
- 层级：门框和屋檐可遮挡角色。
- 动画：烛火、丹炉微烟、书页轻动。
- 光源：烛台或丹炉至少一个暖光。

### 3.2 灵田

- 色彩：湿土、草绿、露水亮点。
- 物件簇：田埂、药草、木牌、水桶、草边。
- 层级：田埂和草丛让边界自然过渡。
- 动画：作物微摆、露水闪点、草叶摆动。
- 状态：采集前饱满，采集中有粒子，采后变矮或空缺。

### 3.3 山门

- 色彩：灰绿、石阶、树影。
- 物件簇：石阶、裂岩、路牌、树根、风动草。
- 层级：树影/路牌和岩体有遮挡。
- 动画：落叶、风吹草、尘土。
- 状态：裂岩爆破后留碎石，路径打开。

### 3.4 灵泉

- 色彩：冷蓝、青绿、暗部。
- 物件簇：泉眼、水岸石、蓝光草、倒影、漂浮灵气。
- 层级：水岸与地面有过渡，泉边石头可遮挡脚部。
- 动画：水波、蓝色灵气、倒影闪动。
- 光源：冷色 `PointLight2D`。

### 3.5 废阵

- 色彩：暗紫、灰石、尘土。
- 物件簇：断柱、阵眼、残符、碎石、断裂符纹。
- 层级：断柱有前后关系。
- 动画：符纹断续闪烁、尘埃漂浮。
- 状态：显形后断线连成阵路，阵眼从暗到亮。

### 3.6 茶摊

- 色彩：暖黄、市井木色。
- 物件簇：桌椅、茶炉、招牌、茶碗、灯笼、茶客。
- 层级：桌椅和招牌有遮挡，茶客不孤立站点。
- 动画：灯笼摆、茶炉热气、茶客 idle。
- 状态：肉身听片段，元神看到声波方向。

### 3.7 药铺

- 色彩：浅绿、木柜、药草黄。
- 物件簇：柜台、药匣、晾草架、药碾、药铺老板。
- 层级：柜台遮挡角色下半身。
- 动画：晾草轻摆、药炉烟、NPC朝向。
- 状态：试药后角色状态短变，札记记录药性。

### 3.8 断桥

- 色彩：灰木、深阴影、远景蓝灰。
- 物件簇：断木/断石、护栏残片、风线、剑痕、边缘草。
- 层级：桥边前景草和断栏遮挡角色。
- 动画：风流线、远处剑光短闪。
- 状态：御剑只埋线索，剑痕可被显形或元神观察深化。

## 4. 数字硬门槛

- 至少 5 层视觉组织。
- 至少 4 个色彩区域：洞府、灵田、山门、灵泉/废阵。
- 至少 20 个装饰物件，且按簇摆放。
- 至少 3 个局部光源：石灯、灵泉、废阵/洞府烛火。
- 至少 5 类环境循环动画。
- 默认截图不得是大色块硬切地图。

## 5. 结论

画面高级感来自“分层和组织”，不是把更多贴图随机放上去。每个场景点必须有自己的色彩、物件簇、动画和状态变化。
