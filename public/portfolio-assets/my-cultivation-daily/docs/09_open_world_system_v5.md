# 《我的修仙日常》大世界自由探索系统修订 v5

## 1. 结论

最终项目是**单机大世界修仙生活模拟**，不是顺序教学关，也不是把系统切成一条固定任务链。

Demo 可以缩小空间，但不能缩小系统思想。它必须像大世界的一块样本，而不是“读札 -> 学符 -> 找NPC -> 炸岩 -> 蒲团 -> 传音 -> 结尾”的线性流程。

## 2. 世界不是关卡，世界是可反复进入的规则场

本项目继续保留以下底层方向：

- 单机独立。
- BOTW式少量底层规则反复组合。
- 《大侠立志传》式非线性江湖、NPC、功法、奇遇密度。
- UI/UX v4 的默认主画面不显示变量总账。
- 真实像素资产和许可记录要求。

但要明确一点：

- 能力不是钥匙孔。
- 传音不是任务广播。
- 感悟不是蒲团专属。
- 元神出窍不是蒲团专属。
- 修仙不是按顺序刷完一串系统按钮。

世界应当像一张可以多次回访的规则网。玩家每次进入，都可能从不同地点、不同对象、不同状态得到新的理解。

## 3. 四类自由入口

Demo 和大世界都应至少支持四类入口，而且这些入口彼此交叉，不要求固定顺序。

| 入口类型 | 玩家从哪里进入 | 可能得到什么 | 不能被降格成什么 |
| --- | --- | --- | --- |
| 环境入口 | 风向、地脉、岩障、灵气流、昼夜、天气、地形 | 隐藏层、可破坏对象、路径、异常点 | 单纯任务箭头 |
| 人物入口 | NPC、门派、散修、茶客、药铺、路人 | 传闻、交易、关系变化、冲突、误导 | 任务广播机 |
| 修行入口 | 试符、炼丹、调息、失败、复盘、材料碰撞 | 感悟、心境变化、规则理解、状态变化 | 经验条领奖 |
| 元神入口 | 任意相对安全地点的短时出窍、远观、侧听 | 信息层、残响、痕迹、他人看不见的结构 | 蒲团专属按钮 |

四类入口不需要都通向同一个结尾。它们的作用是让玩家从不同视角确认：世界有规则，而且规则可以被多次、不同方式理解。

## 4. 传音是信息生态，不是推进频道

传音不应承担“唯一任务提示”职责。

它更像一个有立场、有噪声、有残缺的信息生态：

- 有时清晰。
- 有时断片。
- 有时只是闲聊、交易、误会或暗号。
- 有时受距离、遮挡、天气、阵法、心境和元神状态影响。
- 有时能补线索，但不该成为唯一推进路径。

御剑线索也不应只来自传音。它可以来自：

- 远处剑鸣。
- 高台风流变化。
- 山崖剑痕。
- NPC对话残片。
- 古籍残句。
- 元神状态看到的残影。
- 传音。

传音只是生态中的一支，不是总控广播。

## 5. 感悟可以随时发生

感悟不能只在蒲团上产生。

玩家可以在很多时刻自然获得感悟，例如：

- 第一次看到符箓让空气墙显形。
- 试着炸开岩障后，看见灵脉流向。
- 元神状态听见肉身听不见的信息。
- 炼丹失败，反而看见药性冲突。
- 雨天灵气沿山沟流动。
- 夜里风声改变了传音的清晰度。
- NPC的行为和玩家的功法互相印证。
- 战斗或碰撞触发护体符。

蒲团的作用不是垄断感悟，而是：

- 安神。
- 复盘。
- 深化。
- 帮助突破。

也就是说，蒲团是“整理感悟”的地方，不是“唯一能产生理解”的地方。

### 5.1 感悟来源

至少应支持这些来源：

1. 观察异常环境。
2. 使用能力成功。
3. 使用能力失败。
4. 战斗或受击。
5. 炼丹、制符、试药。
6. 天气、昼夜、季节变化。
7. 地脉、灵泉、岩障、风口等地形变化。
8. NPC 行为、态度、冲突和妥协。
9. 重复失败后换路。
10. 梦境、静坐、复盘。

## 6. 元神出窍不是蒲团专属

元神出窍可以在多数相对安全地点尝试，不应只绑定蒲团。

更合理的规则是：

- 玩家可以在相对安全处短时出窍。
- 风险受心境、肉身安全、环境扰动、阵法、距离和灵压影响。
- 蒲团、静室、灵泉、阵眼、古树下、结界边缘等可以作为“安全锚点”。
- 锚点不是唯一入口，只是降低风险、延长时间、方便复盘。

### 6.1 元神出窍的基本条件

| 条件 | 说明 |
| --- | --- |
| 心境 | 心境越乱，越容易失控、偏航或提前拉回 |
| 肉身安全 | 肉身不能处于明显危险中 |
| 环境扰动 | 大风、雷雨、灵压、爆炸、敌意都会加大风险 |
| 距离 | 离肉身越远，心神消耗越高 |
| 锚点 | 安神地点能降低风险、延长时间、提升稳定性 |

### 6.2 安全锚点不是专属锚点

可作为锚点的例子：

- 蒲团。
- 静室。
- 灵泉旁。
- 阵眼边。
- 古树下。
- 洞府安全角落。

危险地点也可以强行出窍，但要承担风险。这会让出窍成为“能力选择”，而不是“固定按钮”。

## 7. 能力是世界动词

显形、爆炸、护体、御剑、丹药、元神、传音，都应该是能作用于世界的动词，而不是钥匙孔。

| 能力 | 世界动词含义 | 不是 |
| --- | --- | --- |
| 显形 | 看见隐藏结构、灵脉、机关、伪装、痕迹 | 单纯开门按钮 |
| 爆炸 | 改变地形、破坏障碍、打断阵法、制造副作用 | 单纯炸墙技能 |
| 护体 | 抵挡危险、稳定肉身、穿过灵压 | 常驻护盾字条 |
| 御剑 | 跨越距离、到达高处、追踪剑气、运输 | 菜单式飞行解锁 |
| 丹药 | 改变身体、心境、感知、抗性 | 血瓶皮肤 |
| 元神 | 读取信息层、远观、侧听、接触残念 | 蒲团专用模式 |
| 传音 | 远距社交、暗号、误导、求援、监听 | 任务广播频道 |

### 7.1 核心能力的多源获得 / 深化规则

核心能力不是开局全给，也不是固定教学链逐项发放。每个核心能力都应至少有两个非线性入口，且“获得”和“深化”都可以来自不同事件。

| 能力 | 非线性入口 A | 非线性入口 B | 常见深化方式 |
| --- | --- | --- | --- |
| 显形 | 符观残纸、残道人口述、旧阵脚 | 庭院石灯异常、空气墙反应、元神观察到灵性痕迹 | 在不同对象上反复显形，理解隐藏层和符纹逻辑 |
| 爆炸 | 裂纹岩、封石、门派遗留爆符 | NPC交易、野外奇遇、试错中误触可炸对象 | 学会分辨何处该炸、何处不能炸，理解地形副作用 |
| 护体 | 受击危机、低心境时的自动护应 | 雷雨、灵压、炼丹失控、陌生阵法 | 在不同危机中体会护体的防护范围、时机和代价 |
| 御剑 | 高台剑痕、远处剑鸣、断桥残流 | 门派试剑、散修切磋、运输越障需求 | 从移动、追踪、取物、越障等场景理解御剑的用途 |
| 丹药 | 药铺试药、炼丹残页、草药采集 | 炼丹失败、身体状态异常、NPC药性传闻 | 通过不同药性和身体状态理解调息、抗性和副作用 |
| 元神 | 安全地点短时出窍、梦境残响 | 夜路侧听、阵眼观察、灵泉旁试探 | 通过距离、时间、环境扰动理解元神边界和风险 |
| 传音 | 茶摊偷听、路边传闻、门派信件 | 风口回响、阵法折射、残碑回音 | 在不同距离、遮挡和情绪场中理解传音的可靠性 |

这些入口不是顺序链，不要求玩家按固定先后完成。它们的作用是让同一能力可以在不同世界条件下被发现、被确认、被深化。

## 8. Demo 应是开放小区域样本

Demo 不是教学关，而是大世界局部样本。

它要证明的是：

- 世界里有规则。
- 规则能被多种方式理解。
- 不同路线都能产生有效发现。
- 玩家可以自由选择先看环境、先找人、先修行、先出窍。

### 8.1 Demo 的正确形态

Demo 更像这样：

> 一个开放小区域样本。玩家进入后可以自由采集、对话、观察异常、试符、出窍、听传音、复盘感悟。区域里没有唯一正确顺序，只有互相印证的世界线索。

### 8.2 Demo 不能退化成

- 单一路径的教学线。
- 单一钥匙的解谜链。
- 单一触发器的任务列表。
- 单一传音广播式推进。
- 单一蒲团式感悟终点。

## 9. 开放式验证目标

Demo 不必证明“所有系统都完成了”，而要证明以下几件事：

1. 环境能给线索。
2. NPC 能给线索，也能误导。
3. 修行能给线索，但不只靠静坐。
4. 元神能给线索，但不只靠蒲团。
5. 同一现象能有多种入口。
6. 同一能力能服务多种场景。

## 10. 线性链条应被彻底删掉

下面这种表达必须消失：

`读师札 -> 学显形符 -> 找NPC -> 学爆炸符 -> 去蒲团 -> 出窍 -> 听传音 -> 得御剑线索`

正确表达应该是：

- 玩家随时可以从环境、人物、修行或元神任一入口进入。
- 线索可以来自多个来源。
- 感悟可以在多个地点发生。
- 元神可以在多个安全点尝试。
- 收束点可以有多个，不必唯一。

## 11. 参考层级

| 来源 | 用法 |
| --- | --- |
| GDC / BOTW 设计演讲 | 学规则组合、对象响应和玩家发现感 |
| 《大侠立志传》式单机江湖 | 学非线性江湖密度、人物与事件回流 |
| 资料模块校准包和红线 | 学反运营化、信息分层和非调试化表达 |
| UI/UX v4 | 学默认主画面不显示变量总账 |

## 12. 结论

这轮修订要把系统从“线性关卡思维”拉回“开放世界思维”。

世界不是一条链，世界是可反复进入、可多路解释、可在不同状态下重新理解的规则场。
