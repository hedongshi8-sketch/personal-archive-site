# 《我的修仙日常》高级Demo交互反馈规格 v6

## 1. 目标

每个关键交互都必须完成：

`靠近反馈 -> 输入动作 -> 粒子/音效/动画 -> 对象状态变化 -> 札记/菜单归档`

不能只靠 toast 文案说明。

## 2. 通用交互链

| 阶段 | 必须反馈 | Godot建议 |
| --- | --- | --- |
| 靠近前 | 对象本身有可观察异常 | tile/物件状态、循环动画 |
| 靠近时 | 对象轻亮、符纹浮现、交互提示出现 | `Area2D` + highlight shader/tint |
| 输入瞬间 | 角色动作或短暂停顿 | `AnimationPlayer` / `AnimatedSprite2D` |
| 生效中 | 粒子、波纹、尘土、光纹、轻震 | `GPUParticles2D/CPUParticles2D` + Camera2D |
| 生效后 | 世界对象持久变化 | sprite/TileMap/collision/state 更新 |
| 归档 | 札记、符箓匣、传音札或行囊更新 | Menu data，不进主HUD总账 |

## 3. 能力反馈规格

### 3.1 显形

- 靠近前：空气墙、断阵、石灯或剑痕有几乎不可见的闪动。
- 靠近时：当前能力图标微亮，对象边缘有轻微符纹。
- 输入瞬间：角色抬手，符纸或灵光向目标飞出。
- 生效中：符纹沿地面扩散，隐藏线条逐段显出。
- 生效后：空气墙变成可读符阵；废阵断线连通；隐藏灵脉出现。
- 归档：修行札记记录“显形可揭示隐藏层”，符箓匣记录相关对象。

### 3.2 爆炸

- 靠近前：裂岩有缝、尘粒、轻微震动。
- 靠近时：站位太近有短风险提示。
- 输入瞬间：爆符贴附到目标，短暂停顿。
- 生效中：尘土粒子、碎石、轻微屏幕震动。
- 生效后：岩障破碎留场，碰撞区改变，路径打开。
- 归档：札记记录“裂岩可震开，但会损坏部分资源”。

### 3.3 护体

- 靠近前：灵压、雷雨、阵法边缘或危险对象有预兆。
- 靠近时：旧符抖动，不常驻文字说明。
- 输入/触发瞬间：护罩一闪，角色后退或停顿。
- 生效中：短光环和碰撞音。
- 生效后：危险被挡一次，护体符进入符箓匣残页或理解记录。
- 归档：记录触发条件和代价。

### 3.4 元神

- 靠近前：安全锚点有稳定光，危险地带有不稳边缘。
- 输入瞬间：肉身留在原地，元神从角色中分离。
- 生效中：角色半透明，画面色调变冷，声音过滤，灵性痕迹出现。
- 风险：远离肉身时边缘抖动、心神消耗、拉回提示。
- 生效后：回窍时短暂停顿，肉身位置恢复。
- 归档：札记记录锚点、距离、环境扰动对出窍的影响。

### 3.5 传音

- 靠近前：空间有方向性声波或断句残响。
- 肉身状态：只能听片段，声音被遮挡或混响。
- 元神状态：听得更完整，但仍可能残缺、偏向、误导。
- 生效中：声波粒子从具体方向进入，不弹任务广播。
- 生效后：传音札记录片段和来源，不作为唯一推进。
- 归档：关系录/传音札更新“谁说的、在哪里听到、是否可信”。

### 3.6 采集 / 炼丹

- 靠近前：灵草成熟度、药炉烟色、药性光点可读。
- 输入瞬间：角色采集或开炉动作。
- 生效中：草叶粒子、药性粒子、炉烟颜色变化。
- 生效后：草丛变矮/采空，丹药进入行囊；失败也产生药性理解。
- 归档：行囊记录物品，札记记录药性或失败原因。

## 4. 小循环验收

至少两条小循环必须独立成立：

| 小循环 | 交互链 |
| --- | --- |
| 环境观察 | 看见异常 -> 靠近 -> 试符/元神 -> 对象变化 -> 札记归档 |
| 人物信息 | 接近 NPC -> 朝向/气泡 -> 对话/传闻 -> 关系录或传音札归档 |
| 修行试错 | 采药/试丹/试符 -> 成功或失败反馈 -> 状态变化 -> 感悟归档 |
| 元神观察 | 选安全点/强行出窍 -> 视听变化 -> 发现隐藏信息 -> 风险回窍 |

## 5. 一票否决

- 只弹文字，没有对象状态变化。
- 只改变量，没有动画、粒子或音画反馈。
- 显形后看不出世界差异。
- 爆炸后岩障不变。
- 元神只是改角色颜色，没有视听层变化和风险。
- 传音像任务广播，不区分肉身和元神。
- 采集后资源点不变化。

## 6. 结论

高级交互不是“提示更完整”，而是玩家一按键，世界真的产生前因后果。
