## 1. 《星露谷物语》参考拆解

### 资料事实

《星露谷物语》的官方商店页将其定位为开放式乡村生活 RPG，核心包括继承农场、种植、养殖、采矿、钓鱼、战斗、社交与探索。官方 Wiki 中，Seasons 页面明确四季影响作物、采集物、鱼类和活动；Friendship 页面说明与村民通过交谈、礼物和事件提升关系；Farm Buildings 页面说明农场扩建通过建筑物承载生产和生活目标。

### 日程循环

核心结构是“每日时间预算”：玩家每天在种植、浇水、采集、下矿、钓鱼、拜访 NPC、参加节日之间做选择。时间和体力是天然约束，形成轻压力而非强制任务。

### 四季结构

四季让作物、节日、环境资源和玩家目标周期性刷新。季节不是单纯换皮，而是把内容分批开放，让玩家在熟悉规则后进入下一轮规划。

### NPC关系

NPC关系通过日常互动、礼物偏好、生日、剧情事件塑造长期陪伴感。玩家不是单纯刷数值，而是在固定城镇里逐步识别人和生活秩序。

### 农场扩建

农场扩建不是只加面积，而是通过鸡舍、畜棚、鱼塘等建筑改变生产结构。玩家从“手工劳动”逐步转向“组合经营”。

### 轻探索结构

矿洞、野外采集、钓鱼点和季节地图提供低门槛探索。探索与资源、装备、NPC任务相互勾连，但不会压过生活模拟主轴。

### 对《我的修仙日常》的启发

- 把“修炼日”做成类似每日时间预算：灵田照料、打坐吐纳、炼丹、门派差事、拜访师兄弟、外出采药互相竞争。
- 把“四季”转化为“节气/灵气潮汐/月相”：影响灵草成熟、妖兽出没、丹炉火候、闭关收益。
- 把 NPC 关系转化为“师门缘分/道友因果”：送礼可替换为论道、赠丹、帮忙渡劫、共探秘境。
- 农场扩建可转化为“洞府扩建”：灵田、丹房、炼器室、符箓台、聚灵阵、灵兽栏。

### 不应照搬

- 不宜完全复制现代乡村节日和恋爱结构；修仙题材应强调门派秩序、修炼伦理、因果牵连。
- 不宜把每日劳动做得过重，否则“修仙”会变成普通农场换皮。
- 不宜让战斗探索过深，MVP阶段应先保证日常循环成立。

## 2. 《波西亚时光》参考拆解

### 资料事实

《波西亚时光》官方商店页强调玩家继承工坊，通过采集、挖掘、加工、组装和完成订单来经营生活。Wiki 中 Commissions 页面说明订单是工坊推进的稳定任务源；Worktable 等页面说明生产依赖设备、材料和图纸。

### 工坊订单

订单系统把玩家的生产行为绑定到城镇需求。它提供明确短中期目标：接单、备料、加工、提交、获得金钱和声望。

### 生产设备

设备是加工链节点。玩家不是直接把原料变成成品，而是经历切割、熔炼、组装等步骤，形成“计划生产”的体验。

### 城镇建设

城镇项目让个人工坊产出进入公共空间：桥、设施、任务建筑等。这样玩家的生产不是自娱自乐，而是改变城镇状态。

### 资源加工链

资源链强调原料、半成品、成品的层级关系。链条越长，越需要库存管理、设备排程和提前规划。

### 对《我的修仙日常》的启发

- 把工坊订单转化为“门派委托/坊市委托”：炼一炉补气丹、修复阵旗、供奉灵谷、处理灵兽材料。
- 把生产设备转化为“修仙设施链”：药圃产灵草，丹房炼丹，炼器炉炼法器，符台产符箓，阵盘增强洞府。
- 把城镇建设转化为“宗门建设/洞天建设”：修复护山大阵、扩建藏经阁、建设灵兽园。
- 资源加工链可服务轻经营，但应控制长度，避免新手被材料树压垮。

### 不应照搬

- 不宜完整复制复杂工坊排程，否则修仙日常会变成工业生产游戏。
- 不宜让订单完全主导节奏；修仙题材还需要“自我修行”和“机缘”。
- 不宜过早做大型城镇建设，MVP可先做洞府和门派小范围变化。

## 3. 《浮岛物语》参考拆解

### 资料事实

《浮岛物语》官方商店页强调探索、制作、收集、战斗和购买土地扩展世界。Wiki 中 Land、Skills、Structures 等页面说明地块、技能和建筑共同构成快速成长循环。

### 短反馈采集

《浮岛物语》的关键体验是高密度采集反馈：资源刷新快、点击反馈快、升级快。玩家很少长时间等待一个目标完成。

### 地块解锁

购买地块是非常清晰的扩张目标。每块新地带来资源、建筑空间、谜题或敌人，形成“再开一块”的连续驱动。

### 资源链压缩

相比《波西亚时光》，《浮岛物语》的资源链更短、更快、更抽象。它牺牲生活细节，换取爽快成长。

### 自动化成长

建筑、技能和自动采集单位把玩家从手动采集推进到半自动生产。自动化是成长奖励，不是开局负担。

### 对《我的修仙日常》的启发

- 适合借鉴“短反馈”：采灵草、吸纳灵气、炼丹出炉、符箓完成都应有快反馈。
- 地块解锁可转化为“洞府灵脉节点/秘境碎片/山门区域”逐步开放。
- 自动化可转化为“纸人傀儡、阵法代劳、灵兽巡田”，作为中后期减负。
- 技能树可转化为“功法分支/百艺修习”：丹、器、符、阵、灵植、御兽。

### 不应照搬

- 不宜照搬过度抽象的资源刷刷刷，否则会削弱修仙生活的沉浸。
- 不宜让扩张只靠金币购买；修仙题材更适合结合灵脉、机缘、门派许可、境界门槛。
- 不宜把自动化提前给满，否则日常经营缺少建立感。

## 4. 修仙生活化题材补充

### 资料事实

Xianxia 与 cultivation 类型资料通常包含修炼、境界突破、灵气、法宝、丹药、宗门、试炼、天劫等关键词。这些资料适合作为题材语汇来源，但不同作品设定差异很大，不能当作统一规则。

### 可生活化的题材元素

| 元素 | 生活化表达 | 可服务的游戏循环 |
| --- | --- | --- |
| 洞府 | 个人居所、修炼空间、设施布局 | 扩建、装饰、生产、休息 |
| 灵田 | 种植灵草、灵谷、仙植 | 种植、季节、炼丹材料 |
| 炼丹 | 药材配伍、火候、丹炉品质 | 制作、订单、突破准备 |
| 境界 | 练气、筑基等成长段落 | 长期目标、解锁、阶段感 |
| 灵根 | 角色天赋或偏向 | 初始差异、技能分支 |
| 因果 | 人情、承诺、善恶后果 | NPC关系、事件链 |
| 天劫 | 突破风险与仪式 | 阶段考验、资源消耗 |
| 门派日常 | 师门任务、早课、比试、巡山 | 日程、委托、社交 |

### 题材风险

- 修仙语汇天然宏大，容易把 MVP 拉向大世界、战斗、宗门战争。
- 境界和战力体系若过早数值化，会抢走生活模拟主题。
- 炼丹、炼器、符箓、阵法都能单独做成复杂系统，MVP必须压缩。

## 5. 对《我的修仙日常》的 MVP 设计启发

### MVP优先结构

1. 每日修仙日程：早课/灵田/炼丹/门派委托/自由探索。
2. 洞府核心空间：灵田、蒲团、丹炉、储物、简易聚灵阵。
3. 三条轻成长线：境界、洞府设施、NPC缘分。
4. 一个短反馈资源链：灵草 -> 丹药 -> 修炼/委托/关系。
5. 一个中期扩张目标：解锁新灵田或新洞府区域。

### 系统体验模块可优先验证的问题

- 玩家每天最先想做什么：照料灵田、修炼、接门派任务，还是拜访 NPC？
- 境界突破是日常循环的结果，还是阶段关卡？
- 修仙题材的“慢修行”和游戏的“短反馈”如何平衡？
- 洞府扩建是否足够承载玩家长期目标？
- 门派日常是否能替代传统城镇生活模拟的社交中心？

### 推荐取舍

- 从《星露谷物语》借“日程和关系”，不借完整乡村换皮。
- 从《波西亚时光》借“委托和加工链”，不借过长工业排程。
- 从《浮岛物语》借“短反馈和扩张欲望”，不借纯刷资源节奏。
- 从修仙题材借“境界、洞府、灵田、炼丹、因果”，但先做生活化，不急着做大战斗。

## 6. 结论

《我的修仙日常》的清晰方向不是“修仙版农场”或“修仙版工坊”，而是“以洞府和门派为场景的日程生活模拟”。最稳的 MVP 应把玩家放在一个小而可成长的修仙生活圈里：每天分配时间，照顾灵田，炼丹修行，处理门派委托，经营少量关系，并通过境界和洞府扩建获得阶段目标。
