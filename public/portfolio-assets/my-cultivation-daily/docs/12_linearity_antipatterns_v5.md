# 《我的修仙日常》线性化反模式清单 v5

## 1. 目的

这份清单用于防止大世界设计退化成单线教学关或任务流程机。

## 2. 一票否决型线性化反模式

1. 固定顺序链：`读札 -> 学符 -> 找NPC -> 炸岩 -> 蒲团 -> 传音 -> 收束`。
2. 单一钥匙孔：一个能力只对应一个障碍。
3. 单一线索源：传音承担所有推进。
4. 单一地点触发：感悟只能在蒲团发生。
5. 单一出窍点：元神只能在蒲团旁出窍。
6. 单一结论：同一问题只能有一个标准答案。
7. 单一终点：Demo 只能走到固定结尾。
8. 单一入口：玩家必须先做 A 才能做 B。
9. 单一反馈：只弹文字，不改世界对象。
10. 单一阅读层：所有系统都以长文本说明。

## 3. 错误写法与正确写法

| 错误写法 | 正确写法 |
| --- | --- |
| “先学显形符，再找NPC，再学爆炸符” | 环境、人物、修行、元神四类入口都可先进入 |
| “传音会告诉你下一步做什么” | 传音只是信息生态的一部分，可能残缺、偏向、误导 |
| “只有蒲团才能形成理解” | 随时都可能感悟，蒲团只负责复盘和深化 |
| “只有蒲团旁才能出窍” | 多数安全地点都可尝试，蒲团只是安全锚点之一 |
| “拿到能力等于解锁一个门” | 能力应作为世界动词，能改变多个对象 |
| “Demo按固定顺序走完” | Demo 是开放小区域样本，允许多入口和多结论 |
| “所有线索都要汇总到一个任务面板” | 线索分散在环境、人物、札记、传音札和元神视角中 |

## 4. 具体禁止项

- 把“任务推进”写成唯一正确路径。
- 把“传音”写成任务广播。
- 把“感悟”写成蒲团按钮。
- 把“元神出窍”写成固定点技能。
- 把“御剑线索”写成唯一终点奖励。
- 把“玩家理解世界”写成“完成步骤表”。

## 5. 允许的开放结构

允许的结构必须满足至少一条：

- 同一现象可从环境、人物、修行、元神四路进入。
- 同一能力可服务多个对象。
- 同一线索可由多个来源交叉印证。
- 同一地点可在不同时间、天气、状态下产生不同价值。

## 6. 该怎么写才不线性

建议改写时使用这些表达：

- “可从多个入口进入”。
- “不要求固定顺序”。
- “玩家可以先……也可以先……”。
- “该线索只是可能来源之一”。
- “蒲团负责深化，不负责垄断”。
- “元神可在多数安全点尝试，蒲团只是锚点之一”。

## 7. 结论

只要文档里出现“必须先 A 才能 B，必须先 B 才能 C”而且没有开放替代，就要当成线性化风险处理。大世界不是一条线，应该是多入口、多回流、多结论的规则场。
