# 01 活动点子的提出

## 项目定位

项目名暂定为《忍者秘境：影替试炼》。它是一个为《忍者必须死3》设计的限时肉鸽活动概念，目标不是替代主线或竞技内容，而是在原本“跑酷、武器释放、角色培养”的基础上，增加一次局内构筑体验。

面向秋招作品集，本项目的重点是证明系统策划能力：

- 能从现有商业游戏中识别可复用的核心体验。
- 能将竞品机制翻译成目标游戏可接受的系统结构。
- 能输出策划案、PRD、美术需求、配表、demo 和落地计划。
- 能用可试玩原型证明规则闭环，而不是只停留在文字设想。

## 机会判断

《忍者必须死3》的强项是高速跑酷、角色技能、武器释放和养成收集。肉鸽活动适合补足“单局内成长”和“每次开局不一样”的体验：玩家在一次活动局中不断跑完小地图，在终点选择分支奖励，形成临时流派。

《Skul: The Hero Slayer》的可借鉴点是：玩家最多持有两个头骨，通过切换获得差异动作与流派；地图房间结束后通过不同门进入奖励方向；局内道具持续塑造构筑；Boss/章节提供阶段性验证。这些结构可以迁移为忍三的角色位、武器位和地图分支。

## 核心创意

每个小地图是一段短跑酷关卡。玩家跑到终点后看到两个门：

- 武器门：进入后从 3 个局内武器奖励中选择 1 个。
- 角色门：进入后从 3 个局内角色契印中选择 1 个，可补齐双角色位或替换现有角色。

角色相当于 Skul 的头骨，决定基础属性、换人技能和构筑方向；武器相当于 Skul 的装备，提供主动释放、元素标签和套装协同。玩家最终面对章节 Boss 或精英段，用当前构筑验证选择是否成立。

## 设计边界

为了让作品集更像真实项目而不是同人脑洞，设计边界如下：

- 不改动忍三的长期养成价值，只在活动局内生成临时构筑。
- 不要求新角色或新武器美术，优先复用已有角色/武器资产，demo 用占位。
- 不设计付费点，避免秋招作品集变成商业化方案。
- 不复制 Skul 的动作系统，只借鉴“角色槽、道具构筑、门分支、章节验证”的结构。
- 不抓取商业美术资源，demo 主视觉使用原创 2D 水墨风占位图形与程序生成笔刷贴图；若引入第三方占位素材，只用于角色/武器图标衍生，并保留来源与授权边界。

## 一句话提案

在《忍者必须死3》中加入一个“跑酷房间 + 双门奖励 + 双角色切换 + 武器构筑”的限时肉鸽活动，让玩家每局用不同角色与武器组合打出新的流派。
