## 产品目标

为《忍者必须死3》设计一个可复用的限时肉鸽活动框架。通过较短单局、局内随机成长、双门分支和角色/武器构筑，提高活动新鲜感和复玩空间。

## 用户故事

| 编号 | 用户故事 | 验收标准 |
|---|---|---|
| US-01 | 作为玩家，我希望每个小地图结束后有明确奖励选择 | 终点出现武器门和角色门，进入后弹出奖励三选一 |
| US-02 | 作为玩家，我希望局内选择能改变后续体验 | 选择角色会改变速度/技能，选择武器会改变构筑评分和协同 |
| US-02A | 作为玩家，我希望不同角色和武器不只是名字不同 | 角色面板显示差异数值和技能，角色切换会改变移动手感；`J` 键试放当前武器会出现不同视觉效果 |
| US-03A | 作为玩家，我希望跑酷段像忍三局内而不是普通平台跳跃 | 角色在单条横版跑道内用 `W/S` 上下切换身位，障碍和敌人攻击要求玩家判断上位/下位窗口 |
| US-03 | 作为玩家，我希望能形成流派而不是纯随机 | 同标签累计到 2 个时显示协同提示 |
| US-04 | 作为面试官，我希望快速看懂系统闭环 | demo 左侧实时显示章节、房间、角色槽、武器槽、协同和日志 |
| US-05 | 作为开发，我希望规则可配 | 角色、武器、房间、协同读取 `ninja_rogue_catalog.json` |

## 功能需求

### FR-01 开局初始化

- 系统读取活动配置。
- 初始化随机种子。
- 默认给予 1 个初始角色和 1 把初始武器。
- 显示当前章节、房间、角色槽、武器槽和构筑评分。

### FR-02 房间推进

- 玩家从起点移动到终点奖励区。
- 房间状态包含章节、房间序号、房间类型、障碍密度。
- 每完成一个奖励选择后进入下一房间。
- 每章 4 个房间，超过章节数后 demo 循环重置章节。

### FR-03 双门分支

- 终点固定出现左侧武器门、中央关底祭坛、右侧角色门。
- 武器门只决定进入武器奖励池。
- 角色门只决定进入角色奖励池。
- 三选一奖励必须在中央祭坛面板中展开。
- 门视觉必须用颜色/标签区分，祭坛视觉必须与门区分。

### FR-04 奖励候选

- 候选数量：3。
- 候选来自未拥有池。
- 当前 demo 使用随机抽取。
- 后续可加入权重：已激活标签、当前短板、房间难度、保底规则。

### FR-05 角色槽

- 上限：2。
- 获得新角色时，如果槽未满则加入；如果槽满则替换最早角色。
- 当前角色切换到新获得角色。
- 玩家可按 `Tab` 在已有角色间切换。
- 不同角色必须至少表现 3 类差分：角色面板信息、移动/跳跃/冲刺参数、角色剪影/元素色。

### FR-06 武器槽

- 上限：3。
- 获得新武器时，如果槽未满则加入；如果槽满则替换最早武器。
- 武器记录元素、定位、稀有度、冷却、效果说明。
- 当前武器显示在武器面板中。
- 玩家可按 `J` 试放当前武器，不同武器需要有速度、尺寸、颜色或停留时间差异。

### FR-06A 关卡差分

- 房间配置从 `rooms` 读取，按章节和房间序号推进。
- 不同房间显示中文名称、房间类型、难度和障碍密度。
- 原型中障碍数量、障碍颜色和氛围色随房间配置变化。
- 跑酷空间按忍三逻辑处理为单跑道上下切位，不设计双跑道分线；上位/下位只是同一条跑道内的躲避身位。
- `W/S` 切换上位/下位，`Space` 只处理跳跃，不承担换跑道功能。

### FR-07 协同提示

- 统计角色和武器的元素/定位/标签。
- 任一标签数量达到 2，显示为激活协同。
- 协同文字展示在 HUD 中。

### FR-08 复盘日志

- 记录开局、选择奖励、角色切换、章节推进。
- 左侧 HUD 显示最近 7 条日志。

## 非功能需求

- 原型必须能在 Unity 2022.3.62f3c1 打开。
- 不依赖付费插件。
- 不依赖商业 IP 美术资源。
- 所有系统数据应可由配置表修改。
- 单次试玩 1 到 3 分钟内能看懂循环。

## UI 需求

### HUD

- 顶部：项目名、操作提示。
- 中部：章节/房间/当前角色/当前武器/血量预算/战力评分/协同。
- 左侧：角色面板、武器面板、事件日志。
- 底部：中文操作条。

### 奖励面板

- 标题显示“关底祭坛：武器奖励”或“关底祭坛：角色契印”。
- 每个选项展示编号、名称、标签和效果。
- `1/2/3` 选择奖励。
- `Esc` 跳过奖励。

## 埋点建议

| 事件 | 触发时机 | 字段 |
|---|---|---|
| rogue_run_start | 开局 | seed, start_character, start_weapon |
| rogue_room_complete | 到达房间终点 | chapter, room_index, room_type, duration, hp_percent |
| rogue_door_select | 选择门 | door_type, active_synergy, weapon_count, character_count |
| rogue_reward_pick | 选择奖励 | reward_type, reward_id, rarity, tag |
| rogue_character_swap | 手动切换 | from_character, to_character, room_index |
| rogue_run_end | 结束 | result, chapter, completed_rooms, activated_synergies |

## 验收清单

- 能在 Unity 菜单一键生成场景。
- Play 后能移动到两个门。
- 玩家可在单条跑道内上下切换身位，HUD 显示当前身位而不是双路线。
- 两个门分别弹出角色/武器奖励。
- 选择奖励后槽位和日志变化。
- `Tab` 能切换角色。
- 配置 JSON 修改后，重新 Play 能看到名称/数值变化。
- demo 中没有外部商业素材依赖。
