# 02 系统策划案

## 目标体验

玩家进入活动后，不再只依赖局外养成强度，而是在 10 到 15 分钟的单局中完成“跑酷表现 -> 分支选择 -> 构筑成型 -> Boss 验证”的循环。每次障碍组合和战斗压力不同，角色与武器组合不同，玩家可以围绕元素、冷却、爆发、生存、风险收益等方向形成流派。

## 竞品映射

| Skul 结构 | 忍三活动映射 | 设计理由 |
|---|---|---|
| 头骨 | 角色契印/临时角色槽 | 忍三本身以角色为主要能力差异，适合承接头骨身份 |
| 最多持有两个头骨 | 最多持有两个角色契印 | 保留“切换”决策，同时控制 UI 和学习成本 |
| 道具/装备 | 局内武器 | 忍三已有武器记忆点强，适合作为单局构筑核心 |
| 房间门奖励 | 小地图终点双分支门 | 跑酷终点天然适合作为奖励选择节点 |
| 章节 Boss | 章节首领/精英追逐段 | 用高压段验证构筑强度和容错 |
| 金币/商店 | 活动货币与随机补给 | 可扩展，但 demo 阶段不做复杂经济 |

## 核心循环

1. 开局选择初始角色与初始武器。
2. 进入小地图，完成跑酷与轻量战斗压力。
3. 到达终点，选择武器门或角色门。
4. 从 3 个候选中选择 1 个加入构筑。
5. 每 4 个小地图进入章节 Boss 或精英验证。
6. 通关后结算活动积分、成就、图鉴解锁和复盘信息。

## 局内角色系统

角色槽上限为 2。角色承担三类功能：

- 基础手感：移动速度、容错血量、冲刺节奏。
- 换人技能：切换进入时触发短时增益或清屏/护盾/冷却刷新。
- 构筑标签：火、雷、水、风、暗、爆发、连击、控制、生存、风险。

切换规则建议：

- 换人冷却：12 秒。
- 进入新角色时触发入场技能。
- 当前角色死亡时，若另一角色仍可用，则自动切换但扣除活动评分。
- 角色门优先提供不同定位角色，避免连续刷出同质奖励。

## 局内武器系统

武器槽上限为 3。每把武器保留“释放效果 + 冷却 + 标签 + 稀有度”四个核心字段。武器不继承玩家局外强化等级，避免活动平衡失控；可用活动内稀有度和升级来表达成长。

武器类型示例：

- 爆发型：高伤害、长冷却，适合 Boss 验证。
- 连击型：短冷却、多段触发，适合高速跑图。
- 控制型：减速、护盾、清障，适合降低操作压力。
- 机动型：与速度、冲刺、完美闪避关联。
- 风险型：低血量暴击、高收益但低容错。

## 分支房间

每个小地图终点固定出现两个门：

- 左侧武器门：偏向提升战斗强度、构筑标签和主动技能。
- 右侧角色门：偏向改变手感、换人能力和流派核心。
- 中央关底祭坛：门只决定奖励池，真正的三选一结算在祭坛上展开，避免玩家误以为“碰门即发奖”。

后续可扩展第三类门，但作品集 demo 先保留两个门，让核心规则更容易被面试官理解。

## 构筑协同

协同不做复杂长文本套装，采用“标签计数触发”：

- 火 2：武器爆发提升，奖励池提高火系权重。
- 雷/连击 2：冷却降低，切换返还冲刺。
- 水/支援 2：护盾容量增加，障碍减速时间延长。
- 暗/风险 2：低血暴击提升，但治疗奖励权重降低。

这个结构能证明系统策划对“随机性和可读性”的平衡：随机候选仍然可控，玩家能根据标签做预期决策。

## 难度曲线

| 阶段 | 房间数 | 压力来源 | 设计目标 |
|---|---:|---|---|
| 教学段 | 1 | 少量障碍、低速弹幕 | 让玩家理解双门奖励 |
| 成型段 | 2-3 | 单跑道上下切位障碍、精英追击 | 逼玩家选择构筑方向 |
| 验证段 | 4 | Boss/精英首领 | 检查当前构筑是否有效 |
| 循环段 | 5-8 | 更高密度和混合机制 | 产生二次构筑与替换选择 |

## 失败与结算

失败不只显示死亡，而要产生复盘：

- 本局最高章节
- 已获得角色/武器
- 激活协同
- 死亡房间类型
- 推荐下次优先补足的短板

这类复盘对作品集很重要，因为它展示了策划不仅会设计玩法，还会设计验证和迭代入口。

## MVP 范围

当前 Unity demo 覆盖：

- 配表驱动角色/武器/房间/协同。
- 可移动玩家和小地图终点“左武器门 / 中央祭坛 / 右角色门”。
- 武器奖励三选一。
- 角色奖励三选一。
- 双角色槽、三武器槽、替换和切换。
- 中文 HUD、角色面板、武器面板、事件日志。
- 5 个角色的速度、跳跃、冲刺冷却/距离和视觉色差分。
- 6 把武器的图标、稀有度、冷却、构筑标签和 `J` 键试放视觉差分。
- 2 章 8 个关卡的名称、类型、难度、障碍密度和氛围差分。
- 单跑道内的上下切位提示，用 `W/S` 在上位和下位之间切换，表达忍三局内躲避障碍的核心空间判断。
- 基础构筑评分与协同提示。
- 一键生成 demo 场景。

不覆盖：

- 真实忍三动作、战斗和美术。
- Boss AI。
- 长线活动货币。
- 服务端发奖。
- 商业 IP 资源接入。
